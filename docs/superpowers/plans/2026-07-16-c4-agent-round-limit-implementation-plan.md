# C4 运行上限与停止原因实现计划

> 本计划只执行已由用户确认的 C4 设计，不改变 `DEV_SPEC.md` 的架构边界。

## 目标

在现有 `run_agent` 中使用 `AgentDefinition.max_model_rounds` 产生明确的
`agent.limit` 和 `max_model_rounds` 停止原因。

## 步骤

1. 编写失败测试，覆盖达到上限时的状态、错误证据、轮次详情和结果保留字段。
2. 在 C3 的 Tool Call 边界加入轮次守卫。
3. 更新 C4 活动文档为“已实现，待用户验收”。
4. 运行定向测试、全量测试、锁文件检查、构建和差异检查。
5. 用户确认后再提交和合并。

## 明确不做

- 不实现 Tool 执行。
- 不引入完整多轮 Tool 闭环。
- 不运行或伪造 RD-002。
