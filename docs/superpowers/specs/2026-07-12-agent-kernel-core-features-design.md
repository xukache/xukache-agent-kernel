## 1. 章节职责

第二章只回答：

> 这个 Agent Kernel 有哪些最重要的设计特点，这些特点解决什么工程问题，又帮助学习者理解什么？

第二章不承担模块公共契约、完整边界、测试矩阵或确认记录的事实源职责。

## 2. 对比结论

参考文档第二章使用六个能力主题建立项目全貌，每个主题说明能力、实现方式和使用价值。本项目原第二章使用十八节详细描述模块边界，实际职责更接近架构设计。

已确认保留本项目的工程严谨性，同时采用更容易扫描的能力概览结构。

## 3. 已确认结构

```text
2.1 六个原语建立最小心智模型
2.2 从输入到结果的完整执行闭环

2.4 Adapter 驱动的全链路可替换
2.5 结构化结果与可解释运行过程
2.6 渐进式真实对话验证
```

```text

  -> 为什么这样设计
  -> 可以观察到什么
  -> 能从中学到什么
```
