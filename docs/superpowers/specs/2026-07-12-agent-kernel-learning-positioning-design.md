# Agent Kernel 学习定位与第一章设计确认

> 日期：2026-07-12
>
> 状态：已由用户确认
>
> 对应开发规格：DEV_SPEC v0.18

## 1. 用户目标

用户的首要目标是通过亲手设计和实现 Agent Kernel，系统学习 Agent 框架，而不是单纯交付一个业务系统或快速拼装成熟框架。

## 2. 已确认定位

> 本项目以系统学习 Agent 框架为主要目的，以从零实现通用 Agent Kernel 为实践路径，以可运行、可测试、可解释的工程成果验证学习结果。

该定位包含三层含义：

| 层次 | 已确认内容 |
|---|---|
| 首要目标 | 学习和理解 Agent 框架的核心机制 |
| 实践方式 | 逐模块设计、实现并进行真实链路验证 |
| 最终成果 | 形成可复用的通用 Agent Kernel |

## 3. 方案选择

已比较三种第一章叙事方式：

| 方案 | 说明 | 结论 |
|---|---|---|
| A | 学习主线优先，工程成果落地 | 已确认采用 |
| B | 工程项目优先，补充学习目标 | 未采用，学习目标容易退化为附加说明 |
| C | 学习目标与工程目标并列 | 未采用，容易形成两套平行叙事 |

## 4. 第一章职责

第一章只负责回答：

1. 这是什么项目。
2. 为什么要从零实现。
3. 需要学习哪些核心能力。
4. 使用什么方法验证学习结果。
5. 当前阶段覆盖什么、不覆盖什么。
6. 第一阶段最终得到什么。

详细模块职责、依赖禁令、测试场景和版本维护规则由后续对应章节负责。
