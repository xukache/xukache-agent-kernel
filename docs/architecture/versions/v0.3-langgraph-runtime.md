## 完整架构

安安虎是工伤咨询领域 CLI Agent Harness。稳定资产是案件事实、可信 jurisdiction、证据、业务状态转换、Capability 治理、Prompt、Trace、Usage 和 Eval；LangGraph、模型供应商、知识库和 checkpoint 都是可替换实现。

```text
CLI / Eval -> WorkflowRuntime
             -> LangGraphWorkflowRuntime (默认)
             -> NativeWorkflowRuntime (runtime=native 显式回归)
           -> 阶段服务 -> StatePatch -> 项目 reducer -> WorkflowState / WorkflowResult
           -> CapabilityGateway -> ToolExecutor -> TraceRecorder
```

`RunRequest`、`WorkflowState`、`StatePatch`、`WorkflowResult`、`StopReason`、`CapabilityRequest/Result` 和 `TraceEvent` 都是项目协议。domain、application、Agent、Capability、Trace、Eval 和这些公共协议不得导入 LangGraph 类型。

阶段固定为：`understand -> merge_facts -> validate_facts -> clarify | resolve_jurisdiction -> plan -> execute -> validate_evidence -> compose -> safety -> complete`。Agent 无状态，只返回项目结构化输出；阶段服务返回 patch；Reducer 是唯一合并状态的位置，负责 patch 去重、阶段校验、覆盖写入和按业务 ID 合并。CapabilityGateway 是唯一能力执行入口，拥有权限、schema、超时、幂等、错误归一和工具 trace 语义。

## LangGraph 边界

`runtimes/langgraph/` 内的图状态投影只保存项目 `WorkflowState`、当前 `StatePatch` 和 reducer 错误。每个业务阶段是薄节点，只调用既有阶段服务并返回 patch；独立 `apply_patch` 节点调用 `reduce_workflow_state()`；条件边只读取项目状态的 `phase`、`status` 和 reducer 错误。

LangGraph 只拥有节点调度与条件路由。本版本不启用 ToolNode 直连、checkpoint、interrupt、复杂并行、后台任务或流式事件；它不定义案件事实、证据、能力、错误码、停止原因、reducer、trace、usage 或 eval schema。

组合根 `create_default_runtime()` 按 `RuntimeSettings.runtime` 选择实现，默认 `langgraph`，`runtime="native"` 用于显式回归。CLI 与 Eval 只依赖 `WorkflowRuntime`。阶段与工具 trace 写入实际 runtime 名称和版本；能力请求携带该归属但不泄漏框架类型。

## 相对 v0.2 的差异

1. 新增最小 `langgraph` 依赖和 `LangGraphWorkflowRuntime`。
2. 默认运行时改为 LangGraph，Native 保留为可配置回归实现。
3. 同一 runtime contract suite 参数化执行两种运行时，覆盖完成、追问、证据不足、能力失败和安全拦截。
4. `CapabilityRequest` 增加项目 runtime 名称和版本，避免工具 trace 将 LangGraph 调用误标为 Native。

## 兼容性、计划与验收

`WorkflowRuntime.invoke()` 的输入输出、CLI、EvalRunner、业务阶段、ToolExecutor 治理语义和 JSONL 证据格式保持兼容。没有 checkpoint 数据需要迁移。实施计划为 `docs/superpowers/plans/archive/2026-07-10-framework-neutral-langgraph-evolution.md` 的任务 30。

验收：默认选择 LangGraph；Native 可显式选择；两实现使用同一 contract suite；公共模块不导入 LangGraph；不启用 ToolNode、checkpoint、interrupt 或并行。

## 已知限制

当前仅有 CLI，模型和政策检索仍是确定性 fake provider 与本地 fixture；没有 HTTP、WebSocket、前端、真实 ModelGateway、真实 KnowledgeGateway 或生产 checkpoint。复杂并行、恢复、流式和真实 provider 必须在后续独立架构版本中演进。
